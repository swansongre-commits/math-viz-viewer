# 초·중·고 수학 시각화

2022 개정 교육과정의 수학 성취기준을 고르고, 도구를 직접 조작하며 탐구하는 웹 앱의 빌드된 뷰어입니다.

- 학교급에서 초등학교, 중학교, 고등학교를 고릅니다.
- 초등은 학년군, 고등은 과목을 선택할 수 있습니다.
- 초등 1~2학년 29개, 5~6학년 45개 활동을 포함합니다. 3~4학년 활동은 준비 중입니다.
- 일부 성취기준은 아직 준비 중이며, 중·고등 활동은 내용 보강이 진행 중입니다.
- `index.html` 한 파일로 동작하며, 내려받아 브라우저에서 열 수도 있습니다.
- 이 저장소는 배포용입니다. 소스에서 빌드한 결과만 올립니다.
